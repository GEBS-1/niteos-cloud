## Слайд 4. Как работает (2–3 мин) — ГЛАВНОЕ ДЕМО

**Заголовок:** От фото до правки за один проход

**Сценарий демо (живой или заранее записанное видео 40–60 сек):**
1. Открыть `/studio` → загрузить фото  
2. Запустить генерацию → показать результат  
3. Включить **красную кисть** / **голубой ластик** → отметить зону  
4. В чат: «убери эти прожекторы» или «поставь линейный свет по карнизу»  
5. Отправить → новый кадр  
6. (Опционально) лайк версии → она уходит в базу удачных примеров  

**Как правильно пользоваться правками (сказать вслух):**
- Красить **весь светильник и луч**, не тонкую линию  
- Голубой = убрать, красный = изменить/добавить  
- Без текста разметка не уходит  
- После правки смотрим новую версию в истории  

**Текст спикера:**  
«Правки — не Photoshop-слой: модель перерисовывает зону по маске, а система жёстко держит остальной фасад. Поэтому зона должна быть явной. Мы доработали очистку остатков кисти и подстановку реальных светильников из каталога, чтобы „поставить прожектор“ опиралось на продукт NITEOS, а не на абстрактное пятно.»

## Слайд 6. Для дилеров и КП (45 сек)

**Заголовок:** Как этим пользоваться в продажах
