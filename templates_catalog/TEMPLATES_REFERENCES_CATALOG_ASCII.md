## NITEOS Concept Light templates/references catalog (ASCII-safe)
Goal: quick, unambiguous mapping from:
- template/senario -> reference image -> prompt source -> used IES constant
- plus the IES files themselves are already copied here: `templates_catalog/ies/`

Note:
- The actual scenario prompt text is stored in files under:
  `exports/mvp-fixtures/scenarios/prompts/{scenario_id}.txt`
- Legacy prompts are generated by backend function
  `build_dealer_legacy_template_prompt()` and use `CLIENT_STYLE_AI_BLOCK` from `cloud_app.py`.

---

### Products -> IES constants (from `cloud_app.py`)
- `magistral` -> `IES_LINEAR`
- `xray` -> `IES_XRAY`
- `ntpark` -> `IES_NT_PARK`

### Which `.ies` file in `templates_catalog/ies/` corresponds to which constant
Inside `templates_catalog/ies/` there are 3 `.ies` files copied from `assets/ies-catalog/`:
- IES_NT_PARK: filename starts with `NT-STEP`
- IES_XRAY: filename starts with `NT-WAY`
- IES_LINEAR: the remaining `.ies` file (the one that is not `NT-STEP*` and not `NT-WAY*`)
