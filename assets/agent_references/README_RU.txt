Референсы Vision Agent Studio (NITEOS)
=====================================

Папка examples/ — фото, с которых агент берёт стиль освещения
(ритм, тип приборов, характер света). Архитектуру здания с референса
на итоговый кадр не копируем.

Папка thumbs/ — уменьшенные превью для быстрого просмотра.
Файл INDEX.json — каталог: id, cluster (стиль), scenario_id, product_ids.
Сейчас в каталоге только файлы, реально лежащие в examples/.

Путь на диске:
  ...\assets\agent_references\examples\

На сервере те же файлы лежат в /opt/niteos-cloud/assets/agent_references/
